# SBTI 人格测试 · 金手指版

基于 [B站@蛆肉儿串儿](https://space.bilibili.com/417038183) 的 [SBTI 人格测试](https://www.bilibili.com/video/BV1LpDHByET6/) 原版改造。

## 金手指功能

- **实时趋势预测** — 答题过程中实时显示 TOP 3 最可能的人格类型，随答题逐渐收敛
- **维度透视** — 点击"维度已隐藏"即可揭示每道题对应的测试维度
- **直接开测** — 去掉了首页，打开即答题
